# Nordium — Site institucional

Landing page estática (HTML + CSS + JavaScript), sem dependências ou etapa de build.

## Estrutura
- `index.html`: página completa
- `assets/hero.jpg`: foto de fundo do hero e da seção final
- `assets/logo-simbolo.png`: símbolo da logo sem fundo
- `assets/favicon.png`: logo completa (ícone da aba)

## Publicar no GitHub Pages
1. Crie um repositório e envie estes arquivos mantendo a pasta `assets`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Aguarde alguns minutos: o site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
